# WDHC SEO Optimization Plan

## Current Status Analysis
**Website:** https://worlddeadhang.com
**Primary Goal:** Increase athlete submissions via organic search
**Secondary Goal:** Build authority for "dead hang" and "grip strength" keywords

## SEO Audit Checklist

### 1. Page Titles (Critical)
**Current:** "World Dead Hang Championship"
**Issue:** Missing descriptive keywords, not unique per page
**Fix:** 
- Home: "World Dead Hang Championship | Official Leaderboard & Competition"
- Submit: "Submit Your Dead Hang Video | World Dead Hang Championship"
- Leaderboard: "Dead Hang Leaderboard | World Records & Rankings"
- Rules: "Dead Hang Competition Rules | WDHC Official Guidelines"

### 2. Meta Descriptions (Critical)
**Current:** Missing or generic
**Fix:** Add unique 150-160 character descriptions:
- Home: "Official World Dead Hang Championship. Submit your dead hang video, see the leaderboard, compete for world records. Join the global grip strength competition."
- Submit: "Submit your dead hang video to the World Dead Hang Championship. Get verified, appear on the leaderboard, compete for world records."
- Leaderboard: "Live dead hang leaderboard with verified athletes. See world records, grip age calculations, and top performers."

### 3. Content Quality (High)
**Current:** Good but could be more comprehensive
**Fix:**
- Add "What is a Dead Hang?" explainer section
- Add "Benefits of Dead Hangs" health/strength content
- Add "Training Tips" blog-style content
- Add athlete success stories

### 4. Headings Structure (Medium)
**Current:** Good hierarchy
**Fix:** Ensure H1 contains primary keyword, H2/H3 support

### 5. Image Optimization (Medium)
**Current:** Missing alt text
**Fix:** Add descriptive alt text:
- Logo: "World Dead Hang Championship logo"
- Athlete photos: "[Athlete Name] dead hang world record"
- Icons: "Video submission icon", "Leaderboard icon"

### 6. Internal Linking (Medium)
**Current:** Basic navigation
**Fix:** 
- Add "Related pages" section
- Cross-link between leaderboard, submit, rules
- Add "Popular athletes" links

### 7. URL Structure (Good)
**Current:** Clean URLs (worlddeadhang.com/submit, /leaderboard, /rules)
**Fix:** None needed

### 8. Duplicate Content (Good)
**Current:** Unique content per page
**Fix:** None needed
