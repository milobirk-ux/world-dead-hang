Design Differences

The two sections now have distinct visual identities:

Struggle Description Section

  • Theme: Battle/Grit/Intensity
  • Colors: Deep red/black gradient
  • Border: Red accent with thick left border
  • Typography: Rajdhani font (bold, military-style)
  • Animation: Subtle shake + border glow
  • Visual Elements: Top/bottom battle lines
  • Emoji: ⚔️ Crossed swords

Motivational Text Section

  • Theme: Achievement/Inspiration/Growth
  • Colors: Deep blue/teal gradient
  • Border: Blue accent with thick top border
  • Typography: Oswald font (clean, modern)
  • Animation: Subtle pulse glow
  • Visual Elements: Radial glow effect
  • Emoji: 🚀 Rocket
