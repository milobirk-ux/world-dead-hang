  • Print styles: Updated height to min-height

For Original Flyer:

  • .flyer: height: 816px → min-height: 816px
  • .flyer: Removed overflow: hidden
  • Print styles: Updated height to min-height

Result: Both flyers now expand to fit their content, ensuring no footer cutoff. The optimized version also has better layout flow with QR codes positioned correctly.
